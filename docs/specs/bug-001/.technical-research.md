# Technical Research - BUG-001

## Architecture Analysis

- `src/app/routes/todos.py:33-37` centralizes sidebar badge calculation in `_get_list_todo_count()`. The create and toggle handlers both call this helper before rendering an HTMX response.
- `src/app/routes/todos.py:243-283` shows the established OOB pattern for todo mutations: mutate database state, recompute the incomplete count, then render a partial that includes `hx-swap-oob="true"` for `list-{{ list.id }}-count`.
- `src/app/routes/todos.py:286-306` is the defect site. `delete_todo()` verifies ownership and deletes the row, but returns a bare `Response(status_code=200)`, so HTMX removes the item from the DOM without receiving the sidebar badge update.

## Existing UI Partials

- `src/app/templates/partials/todo_item_with_oob.html:1-4` composes the main todo row with the sidebar badge OOB update for create/toggle flows.
- `src/app/templates/partials/todo_deleted_oob.html:1-2` already exists and is purpose-built for the delete path. It renders only the badge replacement span, using `list_id` and `count` context.
- `src/app/templates/partials/todo_list_item.html` and the sidebar rendering use `id="list-{{ list.id }}-count"` for the incomplete-count target. The delete response must keep matching that DOM id.

## Test Patterns

- `tests/test_integration.py:163-180` already proves the toggle response carries an OOB swap marker. BUG-001 should add the equivalent proof for delete so the regression is covered at the HTML-response level.
- `tests/test_todos.py:84-92` currently verifies only database deletion. It does not assert that the delete response includes the updated incomplete count or the OOB swap markup.

## Recommended Narrow Fix Shape

- Keep the route HTMX-first: after deleting the todo, compute the new incomplete count with `_get_list_todo_count()` and render `partials/todo_deleted_oob.html`.
- Preserve existing authorization/error behavior unless the failing test reveals a mismatch. BUG-001 is specifically about the missing sidebar count refresh, not broader delete semantics.
